# 风粒子聚散出入场（WindParticleTransition）

结合逐字 SkSL 晶格风蚀着色器、主机托管 `TokenCompleted` 爆发粒子与流线风丝的出入场过渡效果包：

- **风沙刮入聚合入场**：行显现时，丝带风流与自选色粒子从左侧席卷刮入，按从左到右错峰节奏聚合成清晰字句（着色器同步呈现由左向右的晶格凝聚与微光边缘）。
- **已唱词素碎裂后飘退场**：每个词素唱完瞬间起，字形沿风向在着色器中逐步碎裂成晶格粒子，并同步剥离出速度对齐的晶粒精灵、微尘光点与弯曲风丝向后（默认向左）加速旋散；配合 `line.exit`（1.8s）与事件粒子，行尾末字在换句后也能完整碎散飘远。
- **可自定义粒子配色与风场**：支持自由配置粒子主色（`particleColor`）与高光辅色（`accentColor`），以及风向、风速、抬升气流、涡流扰动、晶格尺度与风丝不透明度；无背景依赖，透明导出同样完整生效。
