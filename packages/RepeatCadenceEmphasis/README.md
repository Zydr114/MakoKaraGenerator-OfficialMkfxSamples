# 重复词素递进强调（RepeatCadenceEmphasis）

基于 `TimelineIndex`（含 `TimelineIndex.Ordinal` 精确索引与不区分大小写归一化统计）检测当前演唱词素在之前歌词中的累计出现次数，并在第 2 次及后续重复演唱时呈现逐级递进的鼓点冲击与震颤强调：

- **首次出现保持克制**：词素首次演唱时维持原样；当相同词素在后续歌词再次出现时触发强调。
- **随重复次数多维递进**：
  - **鼓点弹性冲击**：缩放幅度随重复次数递增，叠加鼓面挤压拉伸（squash-and-stretch）与弹性阻尼回弹，高阶重复附带二次余震回击；
  - **高频震颤与倾角抖动**：起唱瞬间释放多谐波阻尼微震与角度抖动，重复次数越高震感越强烈；
  - **升温辉光与字后冲击波**：从初阶暖金色渐进升温至高阶炽红色，字后同步扩散 1～3 道同心鼓点冲击波环、放射状节拍刻度与爆裂微点。
- **零背景依赖**：支持全曲或单分支统计范围、自动过滤空白与标点词素，普通与透明导出均可稳定呈现。
