# 拟态折射棱镜（SDK v2 原型）

`packageVersion: 3` 混合效果包（C# 控制器 `controller` + 整行图像图 `graph` + SkSL 着色器），演示在 SDK v2 能力边界内实现光学玻璃与色彩夺取字幕：

- **入场与待唱态**：文字主体近乎透明，仅依靠对下方背景（支持底层媒体或真实下层合成画面）的弯月面折射扭曲，以及逐像素随背景局部明暗平滑翻转的自适应反差极细描边显形（暗底泛冷白微光，亮底翻转为深色磨砂暗边）。
- **走字激活态**：由 C# 控制器绕开宿主默认的左向右平涂扫光，改以音节中心向四周辐射的“聚光穿透”驱动整颗音节晶体——对正下方模糊背景做高饱和度加权采样并大幅拉高明度与纯度，同步在笔画边缘产生红蓝光学色散与焦散亮斑；结合音频特征（`BassLevel` / `Pulse`）与长音时长门槛触发沸水涟漪折射震荡（SDK 近似人声能量）。
- **已唱与退场态**：走字完成后液态晶体逐步凝固为半透明毛玻璃；行隐藏进入 `ExitReplica` 阶段后，基于背景亮度梯度优先在明暗交界线碎化为折光微粒，并在局部采样半径内向高光亮部消融。
- **透明导出兜底**：检测到 `OutputMode.Transparent` 时自动切换为透明晶体/冷白描边与高光发光兜底样式，确保无背景媒体导出也保持清晰可辨。
