# 光流墨迹与负空间侵蚀（`OpticalInkErosion`）

`packageVersion: 3` 混合效果包（C# 控制器 `controller` + 行级图像图 `graph` + SkSL 着色器 + `Overlay` 晚期墨丝与飞溅点），在 SDK v2 架构边界内实现**画面风场驱动**的暗黑童话风动态字幕：

- **入场与待唱态（负空间锐利正负片翻转）**：以高锐度单色剪影刀刻切入；SkSL 实时采样全分辨率背景亮度与边缘梯度，当高反差主体轮廓或光影切过字幕区域时，相交笔画在暗底翻白、亮底翻墨并形成局部负空间镂空侵蚀，边界保持刀刻般锐度。
- **走字激活态（粗粒度光流风场与鼓点双模态）**：
  - C# 控制器利用 `frame.Media.Sample` 对比当前时刻与 `50ms` 前的背景 `32×18` 特征网格，使用 2×2 Lucas-Kanade 局部光流解算提取全局横移/推拉散度及行内 4 分区水平风场；
  - 存在画面运动风场时，SkSL 沿反向风力做多步平流撕裂（`≤220px` 墨丝、干笔飞白与烟雾），同时 `EvaluateVisuals` 沿历史时间片风场积分绘制突破图外扩上限的弯曲长尾 `DrawTrails` 与溅射 `DrawDots`；
  - 背景静止且遇到 `AudioFeatures` 低频/能量瞬态（或音节起唱瞬态）时，墨迹向四周呈放射状炸开，并在 SkSL 扩散域内捕捉全分辨率背景高反差轮廓边缘，产生短暂的边缘吸附与切向攀爬效果。
- **已唱与退场态（骨架解除与急流冲刷稀释）**：整句唱完及进入 `ExitReplica` 阶段后，由 SkSL 涡流平流 + 渐进噪声阈值侵蚀配合晚期飘散墨丝，顺着当前画面运动轨迹冲刷拉丝直至彻底稀释消散（静止画面下自动以背景明暗梯度流向代替）。
- **透明导出兜底**：在 `OutputMode.Transparent` 下切换为纯色高反差剪影、音频脉冲呼吸辉光与逐字离散退场，保证透明背景渲染稳定通过验证。
