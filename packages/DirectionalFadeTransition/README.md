# 方向淡入淡出（DirectionalFadeTransition）

简洁实用的整行出入场淡入淡出动画效果包（含注音整体跟随与 `line.exit` 1.5s 退场副本支持）：

- **方向独立可选**：入场支持原地 / 从左 / 从右 / 从上 / 从下滑入，出场支持原地 / 向左 / 向右 / 向上 / 向下滑出；将方向设为「原地」或距离设为 `0` 即为纯原地淡入淡出。
- **时序与曲线可调**：入场与出场各自独立配置时长、滑动距离与缓动曲线，并针对超短行自动收束入场时长，出场完成后持续保持零透明防止闪回。
- **零背景依赖**：纯仿射与透明度变换，零每帧堆分配，在普通与透明导出下均可流畅运行。
