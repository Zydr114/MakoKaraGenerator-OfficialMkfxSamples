# 逐字翻转出入场（SDK v2）

- **三维翻折入场**：歌词行在显现时刻（`RevealTimeUs`）起，按字符水平顺序从左往右依次以三轴投影旋转（默认 `X=-75°`、`Y=90°`、`Z=30°`）由侧立细条翻平归位并淡入，同时带动关联注音（`TokenFamilyTarget`）同步旋转。
- **对称翻转退场**：启用 `lineExit`（2.0 秒）与 `line.exit` 能力，在行隐藏后的 `ExitReplica` 阶段按可配方向（默认从左往右）逐字反向翻转并淡出；已退场字符持续保持零透明。
- **长短行自适应与连字安全**：若单行可见时间或退场窗口小于预设总时长，自动等比压缩单字时长与字间延迟；变换前检查 `CanTransformIndependently` 并将投影余弦夹取非零下限，避免奇异矩阵或字簇分区异常。
