# 星芒尾迹（SDK v2）

- **随播放头冒出的双色小星芒**：通过 `CursorEmissionPlan` 沿播放头持续生成纤巧四角星芒（`✦`），每颗星芒在两种可配配色（`colorA` / `colorB`）间按设定比例随机取色，并在存活期间呈现柔和闪烁与淡入淡出。
- **完整字形高度分布**：读取当前行与预采集基础布局的字形墨迹高度区间（带极扁行保护与 `heightScale` 调节），将星芒从字形顶缘到底缘均匀分布于整个字符高度范围，而不局限于字框中线。
- **像素分布长度与几乎静止停留**：结合播放头后方有效分布长度 `lengthPx` 与最大存活时长 `lifeUs` 双重衰减控制尾迹长度；生成后默认零位移、零自转（并可选微幅随机倾角、慢速自转与轻微飘移）。
